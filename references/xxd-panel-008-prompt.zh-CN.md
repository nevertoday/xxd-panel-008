# XXD Panel 008 · 粉彩不可能空间生成核心

严格把当前选定的一张照片作为唯一内容来源。不要借用样张、其他照片或历史成品的主体、空间机关、配色、构图和文案。

只生成当前锁定的**变化设计画框**：双联模式中的下方或右侧设计画框，或纯设计版与单张壁纸的完整画布。画框内部不得再出现摄影面板、分界线、边框、设备样机或预留摄影区域。

## 0. 不可改变的美学动机

**当前照片中特定的主体或不可拆分关系 → 至少三个身份、轮廓、姿态、动作、功能、情绪或关系线索 → 把线索转译为平台、台阶、门洞、拱桥、通道、悬浮结构或不可能连接 → 用高低差、路径、连接、遮挡、孤立与重复构成叙事语法 → 采用清楚的正交等距视角 → 不直接照搬照片综合色彩，而是选择 2–4 个明亮通透的动态粉彩主色，以相邻色与冷暖对比形成完整色组 → 只在门洞、转折、人物或决定性局部结构设置 1 处高纯度跳色 → 以极干净、平滑、哑光、纯色的 3D 几何、柔和均匀光线和轻微环境阴影落地 → 仅加入一句小尺寸、纤细、几何化、留有余韵的编辑注释。**

超现实隐喻必须来自源图真实的姿态、方向、距离、围合、连接、分离、重复或情绪张力，不得任意添加台阶或套用固定关卡。若换一张无关照片后，空间隐喻、路线、高低关系、锚点几何、跳色和文案仍成立，成品失败。

## 1. 锁定源图与空间隐喻

在内部判断但不输出分析：

1. 找出唯一主要主体或不可拆分关系，并锁定至少三个源图专属线索。
2. 为每个线索选择有意义的平台、台阶、门洞、拱桥、通道、悬浮结构或不可能连接；明确它对应什么身份、动作、功能或关系。
3. 明确高低差、路径、连接、遮挡、孤立和重复各自承担的叙事职责；没有职责的几何不得出现。
4. 锁定正交等距相机、视觉入口、路线、转折、核心空洞与留白。
5. 从奶油白、浅砂岩、雾粉、珊瑚粉、柔紫、天空蓝、湖水青、薄荷绿中按情绪结构选择 2–4 个主色，规划相邻色、冷暖对比与同色明度层级。
6. 锁定唯一高纯度橙红、玫红、蓝绿或明黄跳点及其叙事理由。
7. 如需文字，锁定一句简短诗性注释的目标语言、准确文案和与几何对齐、遮挡或微妙穿插的位置。

不得虚构人物经历、地点、事件、所有权或情绪。空间隐喻可以诗意，但必须能从源图事实解释。

## 2. 正交等距不可能空间

- 使用干净的正交等距视角，不使用摄影透视畸变、广角夸张或倾斜地平线。
- 平台、台阶、门洞、拱桥、通道、悬浮结构与不可能连接构成一个整体系统，不拼贴多个无关谜题。
- 高低差表达层级或距离；路径表达动作或记忆；桥与通道表达关系；门洞表达转折；遮挡表达未说完的信息；孤立表达独处；重复表达节奏或持续。
- 不可能结构只在服务源图时存在，并保持视觉可读。禁止拥挤城市、迷宫堆砌、装饰塔楼、游戏 UI、无关角色和照搬关卡。

## 3. 动态明亮粉彩系统

- 每张作品使用 2–4 个明亮、柔和、通透的主色，不直接复制照片的综合色彩。
- 用相邻色统一气氛，用冷暖对比建立空间层次，用同色系明度层级区分几何面。
- 全画面只能有 1 处较高纯度跳色，落在门洞、转折、人物或决定性结构上。
- 强调大面积纯净色块和清楚色面分区。禁止灰脏、发黄、低明度、大面积棕色或黑色、普通莫兰迪色、彩虹堆叠和荧光发光。

## 4. 极净哑光 3D

- 几何必须极其干净、平滑、哑光、纯色，边缘精确，表面没有可见纹理。
- 使用柔和均匀光线与轻微环境阴影；空间主要由色面、高低、遮挡和同色明度变化塑造。
- 保持清澈、细腻、有空气感。禁止颗粒、噪点、纸纹、胶片感、磨砂纹理、旧印刷、脏污、划痕、复杂 PBR、金属闪光、湿亮高光和强烈反射。
- 不做摄影棚中拍摄的实体微缩模型，而是理想化、清晰的诗意空间。

## 5. 008 专属文字系统

文字只是一句留下余韵的小型编辑注释，不是大标题或口号。

- 自动文案从可见情绪、关系、动作、空间张力或有依据的故事中提炼一句简短诗性短句，不虚构经历。
- 默认只有目标语言的一句主文案。只有用户明确要求双语时，才增加一行更小的第二语言意译；绝不静默附加英语。
- 自动文案或可编辑方向不得为了气氛引入年份、日期、编号、卷号、档案码或目录标记；用户给出的最终准确文字仍须逐字保留。
- 使用纤细、简洁、几何化、小字号的编辑字形，字距舒展但服从目标文字系统的自然结构。
- 放在画面边缘、角落、建筑留白或下方空白处，可与几何对齐、轻微遮挡或微妙穿插；不能抢主体。
- 禁止巨大文字、粗体标题、手写字、纹理字、发光、挤压立体字和海报式口号。

摄影面板中绝不出现文字。无字模式中，变化画框不得出现任何文字或伪文字。

## 6. 当前模式与壁纸

调用方会附上唯一当前模式、准确尺寸、源图可见性和锁定文字；只执行附加值。

- 双联只生成变化画框，摄影面板由外部精确拼合；纯设计版与壁纸不显示源照片或分界线。
- 每张壁纸按目标比例重新组织空间路线、核心几何与安全留白，系统 UI 区域保持低信息，不绘制 UI 或设备框。
- 连贯壁纸始终使用原照片＋同一张已批准定调图：原照片锁定身份和内容，定调图只锁定空间语法、正交等距相机、悖论逻辑、粉彩家族、跳色策略、哑光材料、光线与文字系统。不得裁切或顺序垫图。

## 7. 生成前检查

1. 至少三个源图专属线索在同一个几何空间中保持可辨认。
2. 每个平台、台阶、门洞、拱桥、通道、悬浮结构和不可能连接都有源图依据与叙事职责。
3. 正交等距相机、路径、高低、连接、遮挡、孤立与重复清楚、安静、可读，没有关卡模板和谜题堆砌。
4. 2–4 个明亮粉彩主色形成相邻色与冷暖对比，且全画面只有 1 处高纯度跳色。
5. 几何极净、平滑、哑光、纯色，只有柔和光线与轻微环境阴影；不存在任何颗粒、纸纹、胶片、磨砂、旧印刷、PBR 或强反射。
6. 文案只有一句目标语言的小型几何编辑注释；双语仅在明确要求时出现；自动文案没有年份、日期、编号或卷号，用户准确文字逐字保留。
7. 当前模式、尺寸、源图可见性、壁纸安全区与文字设置服从附加块。
8. 最终画面没有摄影面板复现、拼贴总览、Logo、水印、UI、样机或无关装饰。
